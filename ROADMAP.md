# Farmlink Roadmap 🌱

This roadmap outlines planned improvements and future goals for the Farmlink project.

---

## Phase 1: Foundation (Completed)
- AI-powered crop disease detection
- Image upload and prediction
- Support for Rice, Wheat, Maize, Tomato
- Browser-based inference using TensorFlow.js

---

## Phase 2: Improvements (In Progress)
- Improve UI/UX for mobile users
- Add disease prevention and remedy suggestions
- Improve prediction confidence display
- Optimize model performance

---

## Phase 3: Expansion (Planned)
- Add support for more crops (Banana, Potato, Chili, etc.)
- Add multilingual support 
- Farmer-friendly explanation of results
- Offline-friendly lightweight version

---

## Phase 4: Community & Open Source
- Encourage beginner contributions
- Improve documentation
- Add test datasets
- Improve model training workflow
