# Contributing to Farmlink 🌱

Thank you for your interest in contributing to Farmlink!

Farmlink is an open-source AI-powered crop disease detection system aimed at
helping farmers with accessible and affordable technology.

---

## How to Contribute

1. Fork the repository
2. Clone your fork
3. Create a new branch  
   `git checkout -b feature-name`
4. Make your changes
5. Commit with a clear message
6. Push and open a Pull Request

---

## Contribution Ideas
- Add support for new crops
- Improve UI/UX
- Improve model accuracy
- Add disease prevention suggestions
- Add multilingual support (e.g., Malayalam)
- Improve documentation

---

## Code Guidelines
- Keep code clean and readable
- Comment important logic
- Test before submitting PRs

---

## Need Help?
Open an issue or start a discussion — contributions from beginners are welcome!
